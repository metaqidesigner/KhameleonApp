VOICE INTERFACE  (src/components/orb/VoiceController.tsx)
═══════════════════════════════════════════════════════

──────────────────────────────────────────────────────
VOICE INPUT — Speech to Text
──────────────────────────────────────────────────────

Use the Web Speech API (SpeechRecognition):
  const SR = window.SpeechRecognition || window.webkitSpeechRecognition;
  const recognition = new SR();

Configuration:
  recognition.continuous = false
  recognition.interimResults = true
  recognition.lang = 'en-US'    ← user-configurable in Settings

Activation:
  - Click the Mic button in the chat panel input area
  - Double-click the orb
  - Keyboard shortcut: hold Space bar for 0.5s (push-to-talk)
    (only when no input is focused)

While listening:
  → orb enters LISTENING state (gold)
  → chat input shows interim transcript live as user speaks,
    fading cyan text: "Hearing: [interim text]..."
  → a waveform visualiser replaces the input placeholder:
      5 animated bars, heights driven by microphone volume
      (use getUserMedia + AnalyserNode for amplitude)
      bars: cyan, 3px wide, 4px gap, rounded tops
      height range: 4px–24px, animate smoothly

On speech end (silence detected):
  → final transcript populates the input
  → auto-sends after 800ms delay (user can cancel by clicking X)
  → orb returns to ONLINE state during processing
  → then enters SPEAKING state during response streaming

On error:
  → orb flashes red briefly (0.3s) then returns to previous state
  → chat shows: "VOICE INPUT ERROR — [reason]"

──────────────────────────────────────────────────────
VOICE OUTPUT — Text to Speech
──────────────────────────────────────────────────────

Use the Web Speech API (SpeechSynthesis):
  window.speechSynthesis.speak(utterance)

Voice selection (in Settings › Voice):
  → load window.speechSynthesis.getVoices()
  → filter to English voices
  → preferred voices in order:
      "Google UK English Male"
      "Microsoft Ryan Online (Natural) - English (United Kingdom)"
      "Daniel" (macOS)
      "Alex" (macOS fallback)
      First available English male voice
  → user can override in Settings

Utterance configuration:
  utterance.rate   = 1.05    ← slightly faster than default
  utterance.pitch  = 0.9     ← slightly deeper
  utterance.volume = 1.0

When to speak:
  → Auto-speak toggle in Settings (default: OFF)
  → When ON: every AI response is spoken after streaming completes
  → Manual: each AI message has a 🔊 button to replay it
  → Orb enters SPEAKING state while audio plays
  → Orb returns to ONLINE on utterance end

Text pre-processing before speaking:
  Strip markdown: remove **, *, #, `, _, [](), etc.
  Replace: "$" → "dollars", "%" → "percent"
  Replace: "ms" → "milliseconds", "tok" → "tokens"
  Truncate to 800 characters max for long responses
    (speak summary + "...response continues in panel")

Interruption:
  → Clicking the orb while SPEAKING cancels speechSynthesis
  → Mic button while SPEAKING: cancels speech, starts listening
  → ESC key: cancels any active speech

BROWSER COMPATIBILITY
═══════════════════════════════════════════════════════

SpeechRecognition: Chrome/Edge only (not Firefox/Safari)
SpeechSynthesis:   All modern browsers

Graceful degradation:
  If SpeechRecognition not available:
    → Mic button shows with strikethrough tooltip: "Voice input requires Chrome or Edge"
    → Push-to-talk and wake word options hidden in Settings
    → TTS output still works

  If SpeechSynthesis not available:
    → Auto-speak toggle hidden
    → 🔊 buttons hidden on messages
    → orb never enters SPEAKING state from voice (only from streaming)

  Always check before initialising:
    if (!('SpeechRecognition' in window || 'webkitSpeechRecognition' in window))
      setVoiceInputAvailable(false)
    if (!('speechSynthesis' in window))
      setVoicOutputAvailable(false)

INTEGRATION WITH EXISTING MULTI-AGENT SYSTEM
═══════════════════════════════════════════════════════

The orb chat panel uses the same streamAgentChat() function
as the main Agents › Chat page. When a message is sent from the orb:

  1. orbStatus → 'speaking' (cyan, fast rings)
  2. stream tokens into the message bubble progressively
  3. On stream complete:
       a. if autoSpeak: run TTS on the response text
       b. orbStatus stays 'speaking' until TTS finishes
       c. then orbStatus → 'online'
  4. Push event to agentHistory in jarvisStore
  5. Event appears in bottom ticker automatically

When voice input sends a message:
  1. orbStatus → 'online' briefly (processing)
  2. streamAgentChat fires
  3. orbStatus → 'speaking'
  4. TTS plays (if autoSpeak)
  5. orbStatus → 'online'

Wake word flow:
  1. User says "Hey Jarvis, [query]"
  2. Wake word detected → recognition restarts
  3. Full query captured
  4. orbStatus → 'online' → streaming → 'speaking' (TTS)
  5. Full hands-free loop complete

QUALITY REQUIREMENTS
═══════════════════════════════════════════════════════

- Orb is ALWAYS visible on every page, every tab
- Orb position persists across page navigation and refreshes
- Chat panel never covers the top bar or status bar
- Voice recognition permission prompt handled gracefully:
    if denied: show "MICROPHONE ACCESS DENIED" in chat panel
    mic button dims and disables
- Never start listening without explicit user action
  (no auto-start, respects browser autoplay policies)
- All voice state changes reflected in orbStatus immediately
- Waveform animation uses requestAnimationFrame, cancelled on unmount
- Zero memory leaks: recognition and synthesis cleaned up on unmount
- Orb drag does not interfere with page scrolling
- On mobile: orb fixed bottom-right, not draggable,
  tap to open chat, no push-to-talk (use mic button only)
- prefers-reduced-motion: all orb animations at 20% speed,
  waveform bars static at mid-height
