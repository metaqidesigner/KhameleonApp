You are building a full-stack AI command centre that integrates OpenJarvis
(https://github.com/open-jarvis/OpenJarvis) as its backbone. The entire UI must
be completely redesigned from scratch to match OpenJarvis's actual identity:
local-first, efficiency-obsessed, terminal-native, minimal, and data-dense.
Throw away the orbital brain canvas aesthetic entirely. This is not a sci-fi
visualiser. It is a serious personal AI operating system.

═══════════════════════════════════════════════════════
DESIGN PHILOSOPHY — READ THIS FIRST
═══════════════════════════════════════════════════════

OpenJarvis is a Stanford research project. Its UI aesthetic must reflect:
  - Terminal / CLI heritage: monospace everywhere data appears
  - Local-first honesty: always show engine, model, hardware, watts, cost
  - Efficiency as identity: token/s, latency ms, watt·s per query front and centre
  - No decoration for decoration's sake — every pixel earns its place
  - Dark but not "space game" — think VS Code Dark+ meets htop meets Linear

Reference aesthetic: VS Code sidebar + tmux panes + Linear issue tracker
NOT: Iron Man HUD, holographic displays, orbital rings, glowing brains

Color palette — restrained, purposeful:
  Background:    #0d1117   (GitHub dark, not pure black)
  Surface:       #161b22   (cards, panels)
  Surface-alt:   #21262d   (hover states, inputs)
  Border:        #30363d   (dividers)
  Text-primary:  #e6edf3   (main text)
  Text-muted:    #8b949e   (labels, metadata)
  Text-faint:    #484f58   (disabled, placeholders)
  Accent-blue:   #58a6ff   (links, active states, cursor)
  Accent-green:  #3fb950   (online, success, tokens)
  Accent-amber:  #d29922   (warnings, degraded)
  Accent-red:    #f85149   (errors, offline)
  Accent-purple: #bc8cff   (agent type badges)
  Accent-cyan:   #39d353   (activity graph — like GitHub contributions)

Typography:
  UI text:   -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif, 13px
  Data/mono: "JetBrains Mono", "SF Mono", "Fira Code", monospace, 12px
  Headings:  600 weight, NOT uppercase, NOT letter-spaced

Spacing: 4px base unit. Compact by default. No large hero sections.
Borders: 1px solid #30363d. Subtle, not glowing.
Shadows: none except for modals (0 8px 24px rgba(0,0,0,0.4))
Radius:  6px for cards, 4px for inputs/buttons, 2px for badges

═══════════════════════════════════════════════════════
BACKEND  (/backend)
═══════════════════════════════════════════════════════

Same as before — FastAPI bridging OpenJarvis. Keep all endpoints:

  POST /api/ask           → jarvis.ask_full(prompt, agent, tools)
  GET  /api/agents        → list of agent type strings
  GET  /api/health        → { status, engine, model, uptime, tokens_per_sec,
                              watt_per_query, total_queries, total_cost_usd }
  GET  /api/memory/search → memory chunk results
  POST /api/memory/index  → index a local path
  GET  /api/connectors    → list with { id, name, connected, last_sync }
  POST /api/connectors/connect
  POST /api/research      → agent="deep_research"
  GET  /api/mode          → { name: string }
  GET  /api/skills        → installed skills
  POST /api/skills/install
  GET  /api/telemetry     → { queries: [], energy_wh, cost_usd, avg_latency_ms }
  WebSocket /ws/chat      → streaming tokens + metadata

  Health response must include hardware info:
    { status, engine, model, uptime, gpu, vram_gb, tokens_per_sec,
      watt_per_query, total_queries, total_cost_usd, avg_latency_ms }

  WS done message must include:
    { done: true, model, latency_ms, tokens, cost_usd, energy_wh }

requirements.txt:
  fastapi, uvicorn[standard],
  git+https://github.com/open-jarvis/OpenJarvis.git,
  python-dotenv, websockets

.env.example:
  ANTHROPIC_API_KEY=
  OPENAI_API_KEY=
  JARVIS_ENGINE=ollama
  JARVIS_MODEL=llama3.2
