You are building a full-stack AI command centre that integrates OpenJarvis
(https://github.com/open-jarvis/OpenJarvis) as its AI backbone. The entire
UI must be built to look and feel exactly like JARVIS from Iron Man 2:
a multi-monitor, multi-panel holographic dark OS with glowing data panels,
animated circular HUD elements, red accent headers, cyan orbital rings,
and a live news ticker at the bottom.

VISUAL IDENTITY — READ THIS FIRST
═══════════════════════════════════════════════════════

Reference: Iron Man 2 (2010) — Tony Stark's JARVIS interface

Mandatory visual rules:
  - Deep space black backgrounds: #000408 base, #020c14 panels
  - Primary accent: cyan/teal #00d4ff for borders, rings, scan lines
  - Alert/data accent: crimson red #c0152a for panel headers and warnings
  - Secondary data: electric blue #1a4a7a for mid-tones and inactive rings
  - Text: #b8d4e8 primary, #5a8ab0 secondary/muted, #ffffff for key values
  - Gold/amber #c9a84c for selected states and highlights
  - All panels have a glowing cyan border: box-shadow 0 0 8px rgba(0,212,255,0.4)
  - Panel headers: dark red bar (#8b0000 to #c0152a gradient) with white
    uppercase text, small badge reading "CLASSIFIED" or module type
  - Thin scan-line overlay on the whole UI:
      repeating-linear-gradient(transparent 0px, transparent 3px,
      rgba(0,0,0,0.15) 3px, rgba(0,0,0,0.15) 4px)
  - Subtle vignette on outer edges of the viewport
  - All fonts: "Rajdhani", "Orbitron" (for headings), "Share Tech Mono"
    (for data values) — import all three from Google Fonts
  - Uppercase text for all labels, panel titles, and nav items
  - Numeric data always in Share Tech Mono
  - Corner brackets on panels: CSS ::before ::after with cyan L-shaped borders
  - Animated elements: rotating rings, pulsing dots, scrolling data streams
  - HUD circular elements on Dashboard: CSS/canvas orbital rings with tick marks

BACKEND  (/backend)
═══════════════════════════════════════════════════════

FastAPI bridging OpenJarvis. Endpoints:

  POST /api/ask
    Body: { prompt, agent?, tools? }
    Response: { content, tool_results, model, latency_ms, tokens, cost_usd }

  GET  /api/agents
    → ["simple","orchestrator","deep_research","morning_digest",
       "code_assistant","channel_agent","proactive_agent","operative"]

  GET  /api/health
    → { status, engine, model, uptime, gpu, vram_gb, tokens_per_sec,
        watt_per_query, total_queries, total_cost_usd, avg_latency_ms }

  GET  /api/memory/search?q=
  POST /api/memory/index   { path }
  GET  /api/connectors     → [{ id, name, connected, last_sync }]
  POST /api/connectors/connect  { connector }
  POST /api/research       { query }
  GET  /api/mode           → { name }
  GET  /api/skills
  POST /api/skills/install { source }
  GET  /api/telemetry      → { queries, energy_wh, cost_usd, avg_latency_ms,
                               by_agent: Record<string,AgentStats> }
  GET  /api/feed           → last 20 agent events for ticker
  WebSocket /ws/chat       → { token } chunks then
                             { done, model, latency_ms, tokens, cost_usd }

  CORS: allow all origins in dev

requirements.txt:
  fastapi, uvicorn[standard],
  git+https://github.com/open-jarvis/OpenJarvis.git,
  python-dotenv, websockets

.env.example:
  ANTHROPIC_API_KEY=
  OPENAI_API_KEY=
  JARVIS_ENGINE=ollama
  JARVIS_MODEL=llama3.2
