voice ID. Apply this in both the backend .env and the frontend
store default. Do not change anything else.

BACKEND — .env
═══════════════════════════════════════════════════════

Set these values directly in .env (not .env.example):

  ELEVENLABS_VOICE_ID=wDsJlOXPqcvIUKdLXjDs
  ELEVENLABS_MODEL_ID=eleven_turbo_v2_5

═══════════════════════════════════════════════════════
BACKEND — /backend/voice/tts.py
═══════════════════════════════════════════════════════

Update the constant at the top of the file:

  CHANGE:
    ELEVEN_VOICE = os.getenv("ELEVENLABS_VOICE_ID", "")

  TO:
    ELEVEN_VOICE = os.getenv("ELEVENLABS_VOICE_ID", "wDsJlOXPqcvIUKdLXjDs")

So if the .env value is ever missing, it falls back to
this ID automatically rather than failing silently.

TEST SEQUENCE
═══════════════════════════════════════════════════════

After applying these changes, verify the full loop:

  1. App loads
  2. Say "Hello Jarvis"
  3. Orb turns gold (listening)
  4. Speak a query: "What is the status of all systems?"
  5. Orb turns cyan (streaming)
  6. Response streams into chat panel
  7. Audio plays using voice ID wDsJlOXPqcvIUKdLXjDs
  8. Orb stays cyan while audio plays
  9. Audio ends → orb returns to idle blue
  10. Wake word listener restarts automatically
  11. Status bar shows: "👂 LISTENING FOR 'HELLO JARVIS'"

If audio does not play in step 7:
  Check: ELEVENLABS_API_KEY is set in .env
  Check: GET /api/voice/status returns { connected: true }
  Check: browser console for CORS or fetch errors
  Fallback: Web Speech API will activate automatically
